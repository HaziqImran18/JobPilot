Connect the AI model

JobPilot needs a real model. Add an OpenAI API key once and restart the server. Every answer is generated live; there is no offline planner.

  1. Create a key Open platform.openai.com/api-keys and create a secret key. API billing is separate from ChatGPT Plus.
  2. Open .env It sits in the project root, next to .env.example.
  3. Paste the key The line should look like the example below. Keep the file private.
  4. Restart JobPilot Stop the server with Ctrl + C, then run jobpilot serve --port 5055 again. 
OPENAI_API_KEY=sk-...
JOBPILOT_MODEL_FAST=gpt-4o-mini
JOBPILOT_MODEL_STRONG=gpt-4o
JOBPILOT_DAILY_BUDGET_USD=1.00
I have added the key — reload

The key is read from .env on startup. It is never displayed in the UI and is excluded from git.
